mok uses peer-to-peer sync — no server, no account. share the link below and anyone who opens it joins your session in real time.

your session link
how it works
  • each session has a unique room ID in the URL
  • editor content syncs live as you type
  • collaborator cursors appear as coloured highlights
  • peer count shows in the bottom-left corner
heads up
  • pane structure isn't synced — everyone needs to add matching panes manually
  • eval is local — each person hits opt+enter independently
  • session lives only while at least one tab is open
